# Objetivo del capítulo

**En este capítulo se realiza la creación e instalación inicial del proyecto utilizando Next.js, siguiendo las recomendaciones**
**El objetivo es dejar configurado un entorno base funcional sobre el cual se construirán los siguientes capítulos**

**Para generar la estructura inicial del proyecto se utilizó el comando oficial de Next:**
**npx create-next-app@latest practica-nextjs --use-npm --yes**


## Dentro del proyecto, se ejecutó el servidor con:
**npm run dev**

## El proyecto queda disponible en:
**http://localhost:3000**

## Estructura del proyecto
**practica-nextjs/
├─ app/                Estructura principal (App Router)
├─ public/             Archivos estáticos
├─ node_modules/
├─ package.json
├─ next.config.js**
